# Demo Script — PocketProfit (เส้นทางเดโมที่ชนะ)

> เป้า: โชว์ **ทุก DoD (1–5) + F1–F7 + EDGE 1–4 + N1–N3 + AUTH + brand/UI wow** ด้วยตัวเลขเป๊ะ ในเวลากระชับ.
> **แอป:** PocketProfit — "รู้กำไรร้าน ทุกวัน" · **เปิดที่ `http://localhost:3200`**
> **บัญชีเดโม:** `napha@example.com` / `123456789` (seed ใส่ข้อมูลให้ทุกตัวเลขตรง DoD แล้ว).
> เปิดบนมือถือ/หน้าจอแคบ (mobile-first) จะ wow กว่า. **เวลารวม ≤ 8 นาที.**

> ⚙️ **ก่อนเริ่ม (สำคัญ — re-seed ทุกครั้งก่อนเดโม):**
> 1. `bun run seed` (= `bun run prisma/seed.ts`) → reset ข้อมูลเดโมให้ตัวเลขกลับมาเป๊ะ
> 2. `bun run dev` → เปิด **`http://localhost:3200`**
> 3. เปิดแท็บ Dashboard **`http://localhost:4322` → เลือก yu-expenses** ค้างไว้ (ใช้ตอนปิดท้าย)
> 4. เริ่มที่ **light mode** (จะ toggle เป็น dark ตอนเป็น wow beat)

> 🎯 **ตัวเลขจริงในเดโม (จาก seed — จำให้แม่น):**
> กำไรวันนี้ **+฿300** (เมื่อวาน +฿200 → "ดีกว่าเมื่อวาน") · กำไรเดือนนี้ **+฿500** · เดือนก่อน **+฿6,200** · เป้ารายได้ **13,000/20,000 = 65%** · ค่าวัตถุดิบ **8,100/8,000 (เกินงบ −100)** · มาม่า **margin 50%** · ถุงหูหิ้ว **margin 10% (ต่ำ)**

*(ถ้าต้องประหยัดเวลา: persona + pain + "PocketProfit รู้กำไรร้านทุกวัน — เปิดมาเห็นกำไรวันนี้ทันที กรอก 3 แตะ" พอ.)*

## 1) หน้า Login — first impression ของแบรนด์ (≈30 วิ) · ครอบ AUTH-5, AUTH-2

> **เริ่มที่หน้า login เลย** เพื่อให้กรรมการเห็นแบรนด์ก่อน.
1. เปิด URL หน้าในแอปตรง ๆ (เช่น `/profit`) → **เด้งไป `/login`** ทันที *(AUTH-5)*. พูด: "ยังไม่ login เปิดหน้าในแอปไม่ได้ เด้งมา login".
2. **ชี้แบรนด์ที่หน้า login:** โลโก้ **ดวงอาทิตย์/เหรียญ ฿** ในการ์ดเรืองแสงอุ่น + ชื่อ **"PocketProfit"** + แท็กไลน์ **"รู้กำไรร้าน ทุกวัน — จดรายรับ-รายจ่าย ดูกำไรง่ายๆ อุ่นใจทุกวัน"** + footer "ข้อมูลร้านของคุณเก็บเป็นส่วนตัว ปลอดภัย 🌤️". พูด: "โทนอุ่นแบบร้านชำไทย ออกแบบให้พี่นภาที่กลัวเทคโนโลยีรู้สึกเป็นกันเอง ไม่ใช่แอปบัญชีที่น่ากลัว".
3. *(ออปชัน robust)* ใส่รหัสผิด → ขึ้น **"อีเมลหรือรหัสผ่านไม่ถูกต้อง"** (ภาษาไทย ไม่ใช่ error ดิบ) *(AUTH-2)*.
4. Login จริง: `napha@example.com` / `123456789` → เข้าหน้าหลัก.

## 2) หน้าหลัก Today — **PROFIT HERO** หัวใจของแอป (≈75 วิ) · **wow #1** · ครอบ DoD-3(วัน), F3, F1, DoD-2/F5 alert

> นี่คือ beat ที่ต้องเล่นให้สุด — ทุกอย่างที่พี่นภาอยากรู้อยู่ในจอเดียว.
1. **Profit Hero** การ์ดไล่สีครีม→อำพัน: ตัวเลข **"+฿300"** ใหญ่มาก **นับเลขขึ้น (count-up)** ตอนโหลด + Badge เขียว **"กำไร"** + ประโยค **"😊 ดีกว่าเมื่อวาน เก่งมาก"**. พูด: "เปิดแอปมาเห็นเลยว่าวันนี้กำไร +300 บาท — ระบบเทียบกับเมื่อวานให้ (เมื่อวาน +200) แล้วให้กำลังใจ. ไม่ต้องคิดเลขเอง" *(DoD-3 รายวัน, F3)*.
2. ใต้ hero: **พิลล์ รายรับ (เขียว) / รายจ่าย (แดง)** ของวันนี้ + ลิสต์รายการวันนี้ด้านล่าง *(F1 ลิสต์)*.
3. **ชี้การ์ดเตือนสีแดง 2 ใบ** (โผล่ใต้ hero ทันที):
   - **"ใช้เกินงบ 1 หมวด — ค่าวัตถุดิบ (฿8,100/฿8,000)"** *(DoD-2 เห็นแต่หน้าแรก)*
   - **"สินค้ากำไรขั้นต้นต่ำ 1 รายการ — ถุงหูหิ้วใส่ของ (10%)"** *(F5 เห็นแต่หน้าแรก)*
   พูด: "ระบบเตือนเชิงรุกตั้งแต่หน้าแรก — เกินงบหมวดไหน สินค้าไหนกำไรต่ำ พี่นภาไม่ต้องไปหาเอง".
4. ชี้การ์ดเล็ก **"เป้ารายได้ มิ.ย. — แถบ 65%"** (สรุปย่อของ DoD-4 ไว้เกริ่น).

## 3) บันทึกรายการ + DoD-1 (แนบสลิป) (≈75 วิ) · ครอบ F1, DoD-1, N3

1. กด **FAB "+ บันทึกรายการ"** (ปุ่มลอย) → dialog เปิดเกือบเต็มจอ.
2. โชว์ **ลำดับฟอร์มเร็ว**: ประเภท [รายรับ/รายจ่าย] → ช่องจำนวน **autofocus คีย์บอร์ดเลขเด้งเอง** (`inputMode`) → เลือกหมวด → วันที่ default วันนี้. พูด: "ออกแบบให้กรอกจบใน 3 แตะ — พี่นภากรอกขณะมือยังทอนเงิน".
3. **DoD-1:** เลือก **รายจ่าย**, ใส่ **2000**, หมวด **ค่าใช้จ่ายจิปาถะ**, กด **"ถ่าย/แนบรูป"** แนบรูปใบเสร็จ → เห็น thumbnail → **บันทึก**.
4. รายการเด้งขึ้นบนสุดของลิสต์ทันที + toast "บันทึกรายการแล้ว" *(F1)*.
5. กด **thumbnail รูป** ในลิสต์ → **เปิดดูรูปใบเสร็จเต็มได้** *(DoD-1 ครบ)*.
6. *(N3 ออปชัน)* เปิดบันทึกอีกอันแล้วสลับ **"มี VAT 7%"** → โชว์ "ก่อน VAT / VAT / รวม" คำนวณสด.

## 4) EDGE-2 + EDGE-4 — กันซ้ำ / ยอดผิดปกติ (≈75 วิ) · **จุดโชว์ Output Quality**

1. **EDGE-2 (ซ้ำ):** บันทึกรายการ วันที่+จำนวน+หมวด **เดียวกับที่เพิ่งบันทึก** → ขึ้น **"อาจเป็นรายการซ้ำ"** → เลือก "ยกเลิก" หรือ "ยืนยันบันทึก". พูด: "ตรวจที่ server เลย กัน double-submit จริง ไม่ใช่แค่ disable ปุ่ม".
2. **EDGE-4 (ยอดผิดปกติ):** เลือกหมวด **ค่าวัตถุดิบ** (มีประวัติเยอะ) ใส่ยอดสูงผิด เช่น **50000** → ขึ้น **"ยอดสูงกว่าปกติ"** พร้อมบอกค่าเฉลี่ยหมวด → ยืนยันหรือแก้ก่อน. พูด: "กันพิมพ์ 10,000 แทน 1,000 — เทียบกับค่าเฉลี่ยของหมวดเอง ต้องมีอย่างน้อย 3 รายการก่อนถึงเตือน ไม่งั้นเตือนมั่ว".
3. *(ออปชัน proactive)* ใส่ตัวอักษรในช่องเงิน → "กรอกเป็นตัวเลขเท่านั้น"; เลือกวันที่อนาคต → "เลือกวันที่ในอนาคตไม่ได้".

## 5) งบรายหมวด — DoD-2 (≈45 วิ) · ครอบ DoD-2, F2, N3(VAT summary)

1. ไปหน้า **งบ (/budgets)**.
2. ชี้หมวด **"ค่าวัตถุดิบ" ใช้ไป ฿8,100 จากงบ ฿8,000** → **Badge แดง "เกินงบ"** + แถบ progress แดง + คงเหลือ **−฿100**. พูด: "ใช้/งบ/คงเหลือ + เตือนเกินงบชัดเจน" *(DoD-2)*.
3. ชี้หมวดที่ **"ในงบ"** (เช่น ค่าน้ำค่าไฟ) → ครบทุกสถานะ *(F2)*.
4. ชี้ **การ์ดสรุป VAT รายเดือน** (ภาษีขาย/ภาษีซื้อ/ภาษีสุทธิ) *(N3)*.

## 6) กำไร — DoD-3 (≈45 วิ) · ครอบ DoD-3, F3

1. ไปหน้า **กำไร (/profit)** → แท็บ **รายวัน**: เห็น **Profit Hero เดียวกัน "+฿300"** + กราฟรายวัน.
2. สลับแท็บ **รายเดือน**: การ์ด hero รายเดือน **"+฿500"** + **เทียบเดือนก่อน (พ.ค. +฿6,200)** แสดง **▲/▼ % + "มากขึ้น/น้อยลง"** + กราฟ 6 เดือน. พูด: "เทียบเดือนก่อนเป็น % ไม่มี NaN — ถ้าเดือนก่อนไม่มีข้อมูลจะขึ้น '—' แทน Infinity" *(DoD-3, F3)*.

> *(หมายเหตุ operator: seed ตั้งกำไรเดือนนี้ = +฿500 จริง — ต้นเดือนหลังลงของยกลังยอดยังน้อย เป็นตัวเลขสมจริงและ internally-consistent. ตัวอย่าง "+8,500" ในโจทย์เป็นตัวอย่างต่อฟีเจอร์ ไม่ผูกชุดข้อมูลเดียว. **พูดตามจอ = +฿500**.)*

## 7) เป้าเดือน — **PROGRESS RINGS** (≈45 วิ) · **wow #2** · ครอบ DoD-4, F4

1. ไปหน้า **เป้า (/goals)**.
2. ชี้ **วงแหวนเป้ารายได้** — วง amber **นับขึ้นถึง 65%** ตรงกลางวง, ข้าง ๆ "ทำได้ ฿13,000 / เป้า ฿20,000". พูด: "พี่นภาเก็บเงินส่งลูกเรียน — วงแหวนนี้บอกทันทีว่าใกล้เป้าแค่ไหน 65% แล้ว เห็นเป็นภาพ ไม่ต้องอ่านตัวเลข" *(DoD-4)*.
3. ชี้ **วงแหวนเพดานรายจ่าย** (วงที่ 2, clamp 0–100 กัน NaN) *(F4)*.

## 8) สินค้า & margin — DoD-5 (≈30 วิ) · ครอบ DoD-5, F5

1. ไปหน้า **สินค้า (/products)**.
2. ชี้ **"มาม่าซองใหญ่ ต้นทุน 3 / ขาย 6 → กำไรขั้นต้น 50%"** แสดงทันที *(DoD-5)*.
3. ชี้ **"ถุงหูหิ้วใส่ของ margin 10%" → Badge เตือน margin ต่ำ** (ต่ำกว่าเกณฑ์ 20%). พูด: "รู้เลยว่าของไหนขายแทบไม่ได้กำไร ควรขึ้นราคาหรือเลิกแถมฟรี — เป็นการ์ดเตือนใบเดียวกับที่เห็นบนหน้าแรก" *(F5)*.

## 9) ค่าใช้จ่ายประจำ + EDGE-3 (≈45 วิ) · ครอบ F6, EDGE-3

1. ไปหน้า **ประจำ (/recurring)**.
2. ชี้ **"ค่าเช่าร้าน 3,000/เดือน"** + สถานะ "สร้างแล้วเดือนนี้" → ระบบลงให้อัตโนมัติเมื่อถึงเดือนใหม่ *(F6)*. พูด: "ไม่มี cron — ระบบสร้างให้ตอนเปิดหน้า แบบ idempotent กดรีเฟรชกี่ครั้งก็ไม่ซ้ำ".
3. **EDGE-3:** กด **"ข้ามเดือนนี้"** → ยืนยัน → ยอดเดือนนี้ไม่รวมค่าเช่า แต่รูปแบบยังอยู่. พูด: "เดือนนี้ไม่จ่ายค่าเช่า กดข้ามได้ เดือนหน้ากลับมาเอง ไม่ต้องลบแล้วสร้างใหม่". กดยกเลิกการข้ามให้ดูว่ารายการกลับมา *(EDGE-3)*.

## 10) แก้ย้อนหลัง + ประวัติ — EDGE-1 / F7 (≈45 วิ) · **wow: audit trail**

1. ไปหน้า **รายการ (/entries)** → เลือกรายการหนึ่ง กด **แก้**.
2. แก้จำนวนเงิน → ระบบ **บังคับกรอกเหตุผล** (ลองเว้นว่าง → "กรุณาระบุเหตุผลในการแก้ไข") → ใส่เหตุผล → บันทึก *(EDGE-1)*.
3. เปิด **"ประวัติการแก้ไข"** → เห็น **ค่าเดิม → ค่าใหม่ + เหตุผล + เวลา** (seed มีตัวอย่าง: น้ำอัดลม+ขนม แก้จาก 2,100 → 1,200 "กรอกยอดผิด นับเงินทอนสลับใบ"). พูด: "แก้ได้ แต่ทุกการแก้มี audit — ใครแก้อะไร ทำไม เมื่อไร และรูปใบเสร็จยังอยู่" *(F7)*.

## 11) **TOGGLE DARK MODE** — wow beat (≈15 วิ) · **wow #3**

> ทำตอนนี้ (หรือแทรกตอนอยู่หน้าหลักก็ได้ ถ้าอยากให้ hero เป็น dark).
1. กด **ปุ่มสลับโหมด (Sun/Moon)** บนหัวแอป → ทั้งแอปเปลี่ยนเป็น **โหมดมืดอุ่น (warm near-black)** ทันที, นุ่มนวล, สีแบรนด์ยังอุ่น. พูด: "ร้านเปิดถึง 2 ทุ่ม กรอกตอนกลางคืนได้สบายตา — และจำค่าไว้ เปิดมาครั้งหน้าเป็นโหมดเดิม".
2. กดกลับเป็น light (หรือคงไว้ตามชอบ).

## 12) Export CSV — N1 (≈30 วิ) · ครอบ N1

1. ที่หน้า **/entries** เลือก **ช่วงวันที่** แล้วกด **Export CSV** → ดาวน์โหลดไฟล์.
2. เปิดไฟล์ → ภาษาไทยไม่เพี้ยน (UTF-8 BOM) + มีแถวสรุปรวมท้ายไฟล์ + ตรงช่วงที่กรอง. พูด: "เอาไปส่งบัญชี/ยื่นภาษีต่อได้ และกัน formula-injection ด้วย" *(N1)*.

---

## 13) AUTH-3 + AUTH-4 — isolation + logout (≈45 วิ) · ครอบ AUTH-1/3/4, N2

1. *(N2 ออปชัน)* แวะหน้า **จัดการหมวด (/categories)** → เพิ่มหมวดใหม่ → ใช้เลือกได้ตอนบันทึก *(N2)*.
2. **Logout** (เมนูผู้ใช้ → ออกจากระบบ) → กลับหน้า login *(AUTH-4)*.
3. **AUTH-3:** สมัครบัญชีใหม่ (`/signup`) อีเมลอื่น → เข้าไปเห็น **หน้าว่างเปล่า: hero ฿0, empty state ทุกที่ ไม่มีข้อมูลพี่นภา ไม่มี NaN**. พูด: "ผู้ใช้ใหม่ไม่เห็นข้อมูลของพี่นภาเลย ทุก query ผูก user.id" *(AUTH-1, AUTH-3)*.
4. Login กลับเป็นพี่นภา → ข้อมูลเดิมครบ *(AUTH-4)*.
