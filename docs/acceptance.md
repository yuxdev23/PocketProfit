## Definition of Done (โจทย์ 5 ข้อ — ตัวเลขต้องเป๊ะ)

| ID | สิ่งที่ต้องเห็นในเดโม |
|----|----------------------|
| **DoD-1** | บันทึก 'ค่าหน้าร้าน 2,000 บาท' + หมวด 'ค่าใช้จ่าย' + แนบรูปใบเสร็จ → สำเร็จ + เปิดดูรูปได้ |
| **DoD-2** | หน้าสรุปรายหมวด: 'ค่าใช้จ่าย' ใช้ไป 5,000 จากงบ 8,000 + alert เกิน/ใกล้เกินงบ |

## Feature Chain (F1–F7 — แต่ละฟีเจอร์ใช้งานได้ครบ)

| ID | สิ่งที่ต้องเห็นในเดโม |
|----|----------------------|
| **F1** | บันทึกได้ทั้งรายรับ/รายจ่าย + เลือกหมวด + (ตัวเลือก) แนบสลิป → ขึ้นลิสต์ทันที |
| **F2** | ตั้งงบต่อหมวด/เดือน → สรุปแสดงยอดรายหมวด + % ต่องบ + ป้ายเตือนเกินงบ |
| **F3** | กำไรสุทธิรายวัน+รายเดือน (รายรับ−รายจ่าย) + เทียบเดือนก่อน % ไม่มี NaN |
| **F4** | ตั้งเป้ารายได้ + รายจ่ายต่อเดือน → progress % ของแต่ละเป้า (clamp 0–100) |
| **F5** | เพิ่ม/แก้สินค้า (ต้นทุน+ราคาขาย) → margin % ทันที + เตือนเมื่อต่ำกว่าเกณฑ์ |
| **F6** | ตั้งค่าใช้จ่ายประจำ → สร้างรายการอัตโนมัติเมื่อถึงเดือนใหม่ + เห็นในลิสต์ |
| **F7** | ประวัติการแก้ไขของรายการ: ค่าก่อน/หลัง + เหตุผล + เวลา + ยอดยังกระทบกับรูปใบเสร็จ |

| ID | สิ่งที่ต้องเห็นในเดโม |
|----|----------------------|
| **N1** | ส่งออก CSV กรองตามช่วงวันที่ → ดาวน์โหลดได้ + ข้อมูลตรงช่วงที่กรอง |
| **N2** | จัดการหมวดเอง: เพิ่ม/แก้/ลบ → หมวดที่สร้างใช้เลือกได้ตอนบันทึก |

## Edge Cases (โจทย์ 4 ข้อ — ต้องรองรับครบ)

| ID | สิ่งที่ต้องเห็นในเดโม |
|----|----------------------|
| **EDGE-1** | แก้รายการย้อนหลัง → บังคับกรอกเหตุผล + เก็บประวัติ (ก่อน/หลัง+เหตุผล+เวลา) ดูได้ |
| **EDGE-2** | บันทึกที่ วันที่+จำนวน+หมวด ซ้ำเดิม → เตือน 'อาจซ้ำ' + ยืนยันก่อนบันทึก |
| **EDGE-3** | ค่าใช้จ่ายประจำเดือนนี้ไม่เกิด → กดข้ามเฉพาะเดือนนั้น ไม่ลบรูปแบบ เดือนถัดไปกลับมาปกติ |
| **EDGE-4** | ยอดสูงผิดปกติจากค่าเฉลี่ย (10,000 แทน 1,000) → เตือน + ยืนยันก่อนบันทึก |

## Authentication (บังคับ — ใช้งานครบลูปตั้งแต่ register/login)

| ID | สิ่งที่ต้องเห็นในเดโม |
|----|----------------------|
| **AUTH-1** | Register email+password → สร้างบัญชี + เข้าระบบเห็นหน้าหลักของตัวเอง |
| **AUTH-2** | Login ถูก → เข้าได้; ผิด → ข้อความไทยเจาะจง ไม่ใช่ raw 500 |
| **AUTH-3** | Per-user isolation: ผู้ใช้ B ไม่เห็นข้อมูลของผู้ใช้ A (ทุก query ผูก user.id) |
| **AUTH-4** | Logout → ออก + กลับมา login เห็นข้อมูลเดิมครบ |
| **AUTH-5** | ยังไม่ login แล้วเปิดหน้าในแอป → redirect ไป login |

### Proactive quality bar (เพิ่มเองตามพฤติกรรมพี่นภา — หนุน Output Quality)
ตัวอักษร/ว่าง/0/ติดลบ/ทศนิยมเกิน 2 ตำแหน่ง → บล็อก + ข้อความไทยเจาะจง · เพดานจำนวนเงิน · วันที่อนาคต ·
empty state ไม่โชว์ NaN · กันหารด้วย 0 (เป้า/งบ=0) · ขาดทุนแสดงสีแดง · เซฟล้มเหลวไม่ทำข้อมูลหาย ·
ตัดยอดวัน/เดือนตามเวลาไทย (Asia/Bangkok) · ลบรายการสุดท้าย → กลับ empty state ถูกต้อง.
